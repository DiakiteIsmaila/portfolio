Version design améliorée : plus premium, plus moderne et plus proche d'un portfolio Data professionnel.

## Contenu
- Hero avec mockup analytics
- À propos
- Compétences
- 4 projets phares
- Parcours
- Contact
- Animations légères au scroll
- Responsive mobile/tablette

## Déploiement GitHub Pages
1. Créer un dépôt GitHub `portfolio`.
2. Mettre `index.html`, `style.css` et `script.js` à la racine.
3. Ouvrir Settings → Pages.
4. Deploy from a branch → `main` → `/root`.
5. Enregistrer.

## À personnaliser
- Ajouter votre lien LinkedIn.
- Ajouter éventuellement votre CV PDF.
- Ajouter les liens individuels des repos quand ils sont prêts.
- Conserver Trends comme « Projet en cours » tant que le dashboard final n'est pas terminé.
